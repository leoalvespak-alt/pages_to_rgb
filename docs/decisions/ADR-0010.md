# ADR-0010 — React + Vite admin panel (static build)

- **Status:** Accepted
- **Data:** 2026-08-15

## Contexto

The admin panel needs real-time updates (session progress, audit log) without adding a Node.js
server process to the already constrained VPS.

## Decisão

React + TypeScript + Vite. Static build served by existing proxy or backend. No Node.js process
in production. Real-time updates via SSE (Server-Sent Events) from the FastAPI backend.

## Consequências

- Admin panel build is a CI artifact (dist/).
- SSE endpoint provides live session progress without WebSocket complexity.
- Alternative: HTMX/Jinja is acceptable if React implementation proves significantly more complex.

## Alternativas consideradas

- Next.js: rejected — requires Node.js in production.
- Vue.js: acceptable but team familiarity with React stronger.
- HTMX: kept as alternative if React proves disproportionately complex.
