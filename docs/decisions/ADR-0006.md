# ADR-0006 — Structured outputs validated by Pydantic (no regex)

- **Status:** Accepted
- **Data:** 2026-08-15

## Contexto

LLM responses for exam solving must be deterministic: one letter from the allowed alternatives.
Regex-based extraction is brittle and produces silent errors.

## Decisão

All LLM outputs use structured JSON schemas defined as Pydantic models. The LLM is instructed
to produce JSON. Validation is done by Pydantic before any downstream use. Failed schema →
repair retry → provider fallback → FAILED. No regex ever extracts a final answer.

## Consequências

- Solver/Verifier/Arbiter outputs are typed: `{question_number, answer, evidence_ids[], ...}`.
- Answer letter must be one of the question's allowed alternatives (Invariant 7).
- Schema repair is attempted before fallback to DeepSeek.
- `AnswerAttempt.status = FAILED` if both repair and fallback fail.

## Alternativas consideradas

- Regex extraction: rejected — brittle, ambiguous, produces hallucination-adjacent errors.
- Free-text parsing: rejected — no determinism guarantee.
