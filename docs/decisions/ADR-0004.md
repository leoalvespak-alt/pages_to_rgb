# ADR-0004 — Google Document AI + Azure Document Intelligence for OCR

- **Status:** Accepted
- **Data:** 2026-08-15

## Contexto

Exam pages contain printed text, tables, chemical formulas, geometric figures, and handwritten
annotations. A robust OCR pipeline with fallback is required.

## Decisão

Google Document AI is the primary OCR provider. Azure Document Intelligence is the fallback.
PaddleOCR is an optional third-tier provider, disabled by default on the VPS.

## Consequências

- Raw vendor output is stored in `ocr-raw` bucket; only NormalizedOCRResult flows through domain.
- Circuit breaker per provider prevents cascade failures.
- Server continues operating with `PADDLE_OCR_ENABLED=false`.
- Switching OCR provider does not require domain layer changes.

## Alternativas consideradas

- Tesseract only: rejected — poor accuracy on printed exam content.
- Single cloud OCR: rejected — no fallback path.
- Running local Paddle on VPS: rejected — resource constraints.
