# ADR-0003 — Claude Opus 5 as primary LLM, DeepSeek V4 Pro as fallback

- **Status:** Accepted
- **Data:** 2026-08-15

## Contexto

Exam question solving requires high accuracy on Portuguese-language multiple choice questions,
including multimodal content (images, tables, formulas, maps).

## Decisão

Claude Opus 5 is the primary reasoning provider (Solver, Verifier, Arbiter).
DeepSeek V4 Pro is the fallback for technical failures only (timeout, 5xx, schema error after repair).

## Consequências

- Fallback is NEVER triggered by answer disagreement — that goes to Arbiter.
- `session.degraded_mode = true` when DeepSeek is used.
- No model IDs hardcoded — all from settings (`ANTHROPIC_MODEL_*`, `DEEPSEEK_MODEL`).
- Chain-of-thought / reasoning tokens are never stored.

## Alternativas consideradas

- GPT-4o: rejected — Claude outperforms on Portuguese academic content.
- Single provider: rejected — no resilience.
- Local LLM: rejected — VPS resource constraints.
