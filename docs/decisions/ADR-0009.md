# ADR-0009 — Audio format: two rounds, 2s/20s/1s pause structure

- **Status:** Accepted
- **Data:** 2026-08-15

## Contexto

The audio output is played on a JBL speaker during or after the exam. Students need to mark
answers efficiently. The format must be predictable and unambiguous.

## Decisão

The MP3 contains exactly "Questão N. Letra X." for each validated answer, no explanations.
Structure: Round 1 (slightly slower) with 2s between items → 20s silence → Round 2 (normal
speed) with 1s between items. Physical silence generated by FFmpeg concat, not SSML alone.

## Consequências

- Only FinalAnswer.validated=true entries appear in the audio.
- Gate 2 < minimum_ratio → no answer audio generated at all (status audio only).
- Audio validation checks: file size, duration, FFprobe, SHA-256, 20s silence presence.
- TTS: Google primary, Azure fallback.

## Alternativas consideradas

- SSML-only pauses: rejected — provider-dependent behavior, not verifiable.
- Including explanations: rejected — audio would be too long for exam use.
