# ADR-0008 — Redundant capture termination (5 conditions)

- **Status:** Accepted
- **Data:** 2026-08-15

## Contexto

The exam capture must end reliably even if the primary termination signal fails. The Android
device may lose connectivity, the user may forget to signal end, or the visual marker may not
be detected.

## Decisão

Five independent end conditions in priority order:
1. logical_pages >= expected_pages
2. Manual end command
3. Visual marker detected
4. Open-hand gesture (validated: confidence + no exam document + 2 confirmations in 5s)
5. Hard idle timeout (conservative: no upload, no burst in progress, scene consensus)

## Consequências

- `soft_idle` is an alert only — never terminates.
- `hard_idle` requires all sub-conditions satisfied before terminating.
- Open-hand detection requires 2 confirmations — single detection is ignored.
- Each end_reason is recorded with an AuditEvent.

## Alternativas consideradas

- Single manual end: rejected — too fragile for real exam conditions.
- Timer-only: rejected — unpredictable exam duration.
